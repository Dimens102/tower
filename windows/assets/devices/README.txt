Tower Control Home device images
================================

Optional dedicated photos for the Home tab go in this folder.

Tower Control first tries a filename matching the device id or display name,
for example:

  AVR X2800H.jpg
  KPN Media Box.png
  PAC 7.2.jpg
  Z5500 5.1 Audio.png

Supported formats: JPG, JPEG, PNG, BMP.

If no dedicated device image exists, Tower Control currently falls back to the
matching original-remote image so the Home tile still has a useful visual.
