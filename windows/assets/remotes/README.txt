Place the original remote JPG files from Remotes.rar into this folder.

Expected filenames (case-insensitive):
- Denon.jpg
- Dell.jpg
- EUROM.jpg
- HDMI.jpg
- KPN.jpg
- LEDBar.jpg
- Logitech.jpg
- Sony.jpg

The Tower Control sidebar will automatically show the matching remote photo
for supported IR devices when these files are present.
